# Requirements Traceability

This matrix maps every product, interaction, and delivery requirement from
[Product & Technical Specification](../specs/product.md) and
[TUI Experience & Interaction Specification](../specs/tui.md) to the files and
offline tests that implement it. Test names are the `go test` functions that
provide verification evidence across Phases 0–6.
