        01 / THE CATALOG
        
One rig across six package channels.

        
31 AI development tools grouped into Coding Harnesses, AI TUIs, Terminal & Session Management, and Agent Utilities. Uses mise for aqua/ubi/npm/uv and thin adapters for Debian apt and vendor updaters.

      

      

        02 / THE INTERACTION
        
Select visually. Apply deliberately.

        
Click the terminal, then use j/k, Space to toggle, u to queue all outdated tools, g to toggle a category, p to load a profile (Desktop vs. Server), / to search, and a to inspect the dry-run execution plan.

      

      

        03 / THE HANDOFF
        
Every character has a cell.

        
The terminal is rendered as a fixed character grid matching Bubble Tea v2 and Lip Gloss v2. Browser controls and window chrome are review tools only; follow SPEC.md and UX.md for implementation.
